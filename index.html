Setup Guide — GitHub Pages + Supabase

Step 1 — Create a Free Supabase Project

  1. Go to supabase.com and sign up (free)
  2. Click New Project, name it "gls-invoices", choose Singapore region
  3. Set a database password and wait ~2 minutes for it to set up

Step 2 — Create the Invoices Table

In your Supabase project → click SQL Editor in the left sidebar → click New Query → paste this → click Run:

CREATE TABLE invoices (
  id          uuid DEFAULT gen_random_uuid() PRIMARY KEY,
  created_at  timestamptz DEFAULT now(),
  inv_no      text NOT NULL,
  inv_date    date NOT NULL,
  period      text,
  net_sales   numeric(12,2),
  gst_goods   numeric(12,2),
  gross       numeric(12,2),
  commission  numeric(12,2),
  cgst        numeric(12,2),
  sgst        numeric(12,2),
  total       numeric(12,2),
  net_remit   numeric(12,2),
  metadata    jsonb
);

ALTER TABLE invoices ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Allow all" ON invoices FOR ALL USING (true) WITH CHECK (true);

You should see: "Success. No rows returned."

Step 3 — Get Your API Keys

  1. In Supabase, go to Settings (gear icon, bottom of left sidebar)
  2. Click API
  3. Copy the Project URL (e.g. https://abcd1234.supabase.co)
  4. Copy the anon public key (the long string under Project API Keys)
  5. Paste both in the sidebar under ⚙ Configure Supabase and click Save & Test

Step 4 — Host on GitHub Pages (Free)

  1. Go to github.com and create a free account
  2. Click New Repository → name it "gls-invoice-app" → Create
  3. Upload the index.html file to the repository
  4. Go to Settings → Pages in the repository
  5. Under Source: select Deploy from a branch → main → / (root) → Save
  6. Your app will be live at https://yourusername.github.io/gls-invoice-app in ~2 minutes
First use after hosting: Open the app → click ⚙ Configure Supabase in the sidebar → enter your URL and key → Save & Test. Then go to Company Details tab and fill in your addresses and bank details. These are saved in your browser — you only do this once.
